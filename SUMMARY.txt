🚀 QUICK START
─────────────────────────────────────────────────────────────────────

1. TEST THE SETUP
   $ ./test.sh

2. START THE API SERVER
   $ cd torrent-pipe-api && node server.js

3. ADD A TORRENT (new terminal)
   $ cd torrent-pipe-api
   $ node cli.js add "Anime Title" "magnet:?xt=..." --sub

4. PUSH TO GITHUB
   $ git init
   $ git add .
   $ git commit -m "Initial commit"
   $ git remote add origin https://github.com/YOUR-USERNAME/torrent-pipe.git
   $ git push -u origin main

5. UPDATE MANIFEST URLS
   Edit torrent-pipe-provider/manifest.json with your GitHub URLs

6. ADD TO SEANIME
   Extensions → Add extensions → Paste manifest URL

7. SEARCH IN SEANIME
   Search for your anime → See your torrents!

🛠️ COMMAND REFERENCE
─────────────────────────────────────────────────────────────────────

API Server:
  $ node server.js [port]          Start API server (default: 3456)

CLI Commands:
  $ node cli.js add <title> <magnet> [--sub|--dub|--both]
  $ node cli.js list               List all torrents
  $ node cli.js remove <id>        Remove a torrent
  $ node cli.js clear              Clear all torrents

API Endpoints:
  GET    /health                   Health check
  GET    /torrents                 List all torrents
  POST   /torrents                 Add a torrent
  DELETE /torrents/:id             Remove a torrent
  DELETE /torrents                 Clear all torrents

⚠️  IMPORTANT NOTES
─────────────────────────────────────────────────────────────────────

1. Storage Synchronization:
   Provider and API use separate storage by default.
   See SETUP.md Step 5 for integration options.

2. Magnet Link Handling:
   Seanime exposes magnet links but doesn't download torrents.
   You'll need a torrent client configured to handle magnet: URLs.

3. GitHub Hosting:
   Update manifest.json with your actual GitHub URLs before
   adding to Seanime.

4. Legal Compliance:
   Ensure compliance with local laws and tracker ToS.


🔧 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────

Common Issues:

1. "Cannot connect to API"
   → Check server is running: curl http://localhost:3456/health

2. "Provider not showing in Seanime"
   → Verify manifest URL is accessible
   → Check Seanime logs

3. "Torrents not appearing"
   → Verify: node cli.js list
   → Check storage integration (SETUP.md Step 5)
